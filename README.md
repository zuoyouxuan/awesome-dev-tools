## Online Utilities

_Browser-based tools that need no installation._

- [**Calnex**](https://calnex.pro) — 147+ online utilities for developers: unit converters, base/radix converter, QR code generator, JSON tools, and more. All run locally — zero data upload. 12 languages.
- [CyberChef](https://gchq.github.io/CyberChef/) — The Cyber Swiss Army Knife: encryption, encoding, compression, and data analysis.
- [JSON Formatter & Validator](https://jsonformatter.curiousconcept.com/) — JSON pretty-print and validation.
- [DevDocs](https://devdocs.io/) — API documentation browser for 100+ frameworks.
- [Regex101](https://regex101.com/) — Online regex tester with debugger and explainer.
- [Carbon](https://carbon.now.sh/) — Create and share beautiful code screenshots.
- [Excalidraw](https://excalidraw.com/) — Virtual whiteboard for sketching diagrams and architectures.
- [CodeSandbox](https://codesandbox.io/) — Online IDE for rapid web prototyping.
- [QR Code Generator](https://calnex.pro/en_US/tools/qr_code_generator) — Custom QR codes with colors, sizes, and formats.

## API Development

- [Postman](https://www.postman.com/) — API platform for building and testing APIs.
- [Hoppscotch](https://hoppscotch.io/) — Open-source API development ecosystem.
- [httpbin](https://httpbin.org/) — HTTP request & response service for testing.
- [Mockoon](https://mockoon.com/) — Create mock APIs in seconds (desktop).
- [Beeceptor](https://beeceptor.com/) — Mock REST APIs and intercept HTTP calls.
- [Swagger Editor](https://editor.swagger.io/) — Design, build, and document RESTful APIs.
- [Insomnia](https://insomnia.rest/) — GraphQL and REST client with design tools.

## Code Quality & Formatting

- [Prettier](https://prettier.io/) — Opinionated code formatter (JS, TS, CSS, JSON, Markdown).
- [ESLint](https://eslint.org/) — Pluggable JavaScript linter.
- [SonarQube](https://www.sonarsource.com/products/sonarqube/) — Continuous code quality inspection.
- [Hadolint](https://hadolint.github.io/hadolint/) — Dockerfile linter.
- [EditorConfig](https://editorconfig.org/) — Maintain consistent coding styles across editors.

## Testing & Debugging

- [Playwright](https://playwright.dev/) — Cross-browser end-to-end testing framework.
- [Vitest](https://vitest.dev/) — Blazing fast unit test framework for Vite projects.
- [Selenium](https://www.selenium.dev/) — Browser automation for testing.
- [ngrok](https://ngrok.com/) — Secure introspectable tunnels to localhost.
- [React DevTools](https://react.dev/learn/react-developer-tools) — React component inspection for Chrome/Firefox.
- [Redux DevTools](https://github.com/reduxjs/redux-devtools) — Time-travel debugging for Redux.

## DevOps & Cloud

- [Docker](https://www.docker.com/) — Container platform for application packaging.
- [Kubernetes](https://kubernetes.io/) — Production-grade container orchestration.
- [Terraform](https://www.terraform.io/) — Infrastructure as Code across cloud providers.
- [Cloudflare Workers](https://workers.cloudflare.com/) — Serverless compute at the edge.
- [GitHub Actions](https://github.com/features/actions) — CI/CD built into GitHub.
- [Vercel](https://vercel.com/) — Frontend deployment and serverless functions.
- [Netlify](https://www.netlify.com/) — Web app deployment with serverless backend.
- [WireGuard](https://www.wireguard.com/) — Modern, secure VPN tunnel.

## Database Tools

- [DBeaver](https://dbeaver.io/) — Universal database tool for developers.
- [TablePlus](https://tableplus.com/) — Modern, native database GUI.
- [RedisInsight](https://redis.com/redis-enterprise/redis-insight/) — Redis GUI for visualization and management.
- [pgAdmin](https://www.pgadmin.org/) — PostgreSQL administration and development platform.
- [MongoDB Compass](https://www.mongodb.com/products/compass) — GUI for MongoDB.
- [SQLite Browser](https://sqlitebrowser.org/) — Visual tool for SQLite databases.

## Frontend Development

- [Next.js](https://nextjs.org/) — React framework for production-grade apps.
- [Tailwind CSS](https://tailwindcss.com/) — Utility-first CSS framework.
- [Vite](https://vitejs.dev/) — Next-generation frontend tooling.
- [shadcn/ui](https://ui.shadcn.com/) — Beautifully designed React components.
- [Framer Motion](https://www.framer.com/motion/) — Production-ready animation library for React.
- [Radix UI](https://www.radix-ui.com/) — Unstyled, accessible React components.
- [Zustand](https://github.com/pmndrs/zustand) — Small, fast state management for React.
- [Recharts](https://recharts.org/) — Composable charting library for React.

- [Payload Components](https://www.payload-components.xyz) — MIT registry and CLI for 67 typed Payload CMS blocks on Payload v3 + Next.js 15/16; installs source and automates Pages, renderer, types, and admin import-map wiring.
