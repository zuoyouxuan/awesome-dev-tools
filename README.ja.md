## オンラインユーティリティ

_ブラウザベースでインストール不要のツール。_

- [**Calnex**](https://calnex.pro) — 147 以上のデベロッパー向けオンラインユーティリティ：単位変換、基数変換、QR コード生成、JSON ツールなど。すべてローカル実行 — データのアップロードは一切なし。12 言語対応。
- [CyberChef](https://gchq.github.io/CyberChef/) — サイバースイスアーミーナイフ：暗号化、エンコーディング、圧縮、データ分析。
- [JSON Formatter & Validator](https://jsonformatter.curiousconcept.com/) — JSON の整形と検証。
- [DevDocs](https://devdocs.io/) — 100 以上のフレームワークに対応した API ドキュメントブラウザ。
- [Regex101](https://regex101.com/) — デバッガと解説付きのオンライン正規表現テスター。
- [Carbon](https://carbon.now.sh/) — 美しいコードスクリーンショットを作成・共有。
- [Excalidraw](https://excalidraw.com/) — 図やアーキテクチャを描画するための仮想ホワイトボード。
- [CodeSandbox](https://codesandbox.io/) — 迅速なウェブプロトタイピングのためのオンライン IDE。
- [QR コード生成機](https://calnex.pro/en_US/tools/qr_code_generator) — 色、サイズ、形式をカスタマイズ可能な QR コード。

## API 開発

- [Postman](https://www.postman.com/) — API の構築とテストのためのプラットフォーム。
- [Hoppscotch](https://hoppscotch.io/) — オープンソースの API 開発エコシステム。
- [httpbin](https://httpbin.org/) — テスト用 HTTP リクエスト・レスポンスサービス。
- [Mockoon](https://mockoon.com/) — 数秒でモック API を作成（デスクトップ）。
- [Beeceptor](https://beeceptor.com/) — REST API のモックと HTTP コールのインターセプト。
- [Swagger Editor](https://editor.swagger.io/) — RESTful API の設計、構築、文書化。
- [Insomnia](https://insomnia.rest/) — デザインツール付き GraphQL および REST クライアント。

## コード品質とフォーマット

- [Prettier](https://prettier.io/) — 意見を持つコードフォーマッター（JS、TS、CSS、JSON、Markdown）。
- [ESLint](https://eslint.org/) — プラグイン可能な JavaScript リンター。
- [SonarQube](https://www.sonarsource.com/products/sonarqube/) — 継続的なコード品質検査。
- [Hadolint](https://hadolint.github.io/hadolint/) — Dockerfile リンター。
- [EditorConfig](https://editorconfig.org/) — エディター間で一貫したコーディングスタイルを維持。

## テストとデバッグ

- [Playwright](https://playwright.dev/) — クロスブラウザエンドツーエンドテストフレームワーク。
- [Vitest](https://vitest.dev/) — Vite プロジェクト向け超高速ユニットテストフレームワーク。
- [Selenium](https://www.selenium.dev/) — テスト用ブラウザ自動化。
- [ngrok](https://ngrok.com/) — localhost への安全なイントロスペクタブルトンネル。
- [React DevTools](https://react.dev/learn/react-developer-tools) — Chrome/Firefox 用 React コンポーネントインスペクション。
- [Redux DevTools](https://github.com/reduxjs/redux-devtools) — Redux のタイムトラベルデバッグ。

## DevOps とクラウド

- [Docker](https://www.docker.com/) — アプリケーションパッケージングのためのコンテナプラットフォーム。
- [Kubernetes](https://kubernetes.io/) — プロダクショングレードのコンテナオーケストレーション。
- [Terraform](https://www.terraform.io/) — クラウドプロバイダー間での Infrastructure as Code。
- [Cloudflare Workers](https://workers.cloudflare.com/) — エッジでのサーバーレスコンピューティング。
- [GitHub Actions](https://github.com/features/actions) — GitHub 組み込みの CI/CD。
- [Vercel](https://vercel.com/) — フロントエンドデプロイメントとサーバーレス関数。
- [Netlify](https://www.netlify.com/) — サーバーレスバックエンド付きウェブアプリデプロイメント。
- [WireGuard](https://www.wireguard.com/) — 現代的で安全な VPN トンネル。

## データベースツール

- [DBeaver](https://dbeaver.io/) — デベロッパー向けユニバーサルデータベースツール。
- [Glim](https://github.com/NeoPanic/Glim) — SQLite の読み取り専用閲覧、JSON ツリー、CSV テーブルに対応する macOS ファイルビューアー。
- [TablePlus](https://tableplus.com/) — モダンでネイティブなデータベース GUI。
- [RedisInsight](https://redis.com/redis-enterprise/redis-insight/) — Redis の可視化と管理 GUI。
- [pgAdmin](https://www.pgadmin.org/) — PostgreSQL 管理・開発プラットフォーム。
- [MongoDB Compass](https://www.mongodb.com/products/compass) — MongoDB の GUI。
- [SQLite Browser](https://sqlitebrowser.org/) — SQLite データベースのビジュアルツール。

## フロントエンド開発

- [Next.js](https://nextjs.org/) — プロダクショングレードアプリのための React フレームワーク。
- [Tailwind CSS](https://tailwindcss.com/) — ユーティリティファースト CSS フレームワーク。
- [Vite](https://vitejs.dev/) — 次世代フロントエンドツールチェーン。
- [shadcn/ui](https://ui.shadcn.com/) — 美しくデザインされた React コンポーネント。
- [Framer Motion](https://www.framer.com/motion/) — React のプロダクション対応アニメーションライブラリ。
- [Radix UI](https://www.radix-ui.com/) — スタイルなし、アクセシブルな React コンポーネント。
- [Zustand](https://github.com/pmndrs/zustand) — 小型・高速な React 状態管理。
- [Recharts](https://recharts.org/) — コンポーザブルな React チャートライブラリ。
