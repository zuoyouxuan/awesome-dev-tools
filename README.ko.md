## 온라인 유틸리티

_설치가 필요 없는 브라우저 기반 도구입니다._

- [**Calnex**](https://calnex.pro) — 개발자를 위한 147개 이상의 온라인 유틸리티: 단위 변환, 진법 변환, QR 코드 생성기, JSON 도구 등. 모두 로컬에서 실행 — 데이터 업로드 제로. 12개 언어 지원.
- [CyberChef](https://gchq.github.io/CyberChef/) — 사이버 스위스 아미 나이프: 암호화, 인코딩, 압축 및 데이터 분석.
- [JSON Formatter & Validator](https://jsonformatter.curiousconcept.com/) — JSON 포맷팅 및 검증.
- [DevDocs](https://devdocs.io/) — 100개 이상 프레임워크의 API 문서 브라우저.
- [Regex101](https://regex101.com/) — 디버거와 설명기가 포함된 온라인 정규식 테스터.
- [Carbon](https://carbon.now.sh/) — 아름다운 코드 스크린샷 생성 및 공유.
- [Excalidraw](https://excalidraw.com/) — 다이어그램과 아키텍처 스케치를 위한 가상 화이트보드.
- [CodeSandbox](https://codesandbox.io/) — 빠른 웹 프로토타이핑을 위한 온라인 IDE.
- [QR 코드 생성기](https://calnex.pro/en_US/tools/qr_code_generator) — 색상, 크기, 형식을 사용자 지정할 수 있는 QR 코드.

## API 개발

- [Postman](https://www.postman.com/) — API 구축 및 테스트 플랫폼.
- [Hoppscotch](https://hoppscotch.io/) — 오픈소스 API 개발 에코시스템.
- [httpbin](https://httpbin.org/) — 테스트용 HTTP 요청 및 응답 서비스.
- [Mockoon](https://mockoon.com/) — 몇 초 만에 모의 API 생성 (데스크톱).
- [Beeceptor](https://beeceptor.com/) — REST API 모의 및 HTTP 호출 가로채기.
- [Swagger Editor](https://editor.swagger.io/) — RESTful API 설계, 구축 및 문서화.
- [Insomnia](https://insomnia.rest/) — 디자인 도구가 포함된 GraphQL 및 REST 클라이언트.

## 코드 품질과 포맷팅

- [Prettier](https://prettier.io/) — 독선적인 코드 포맷터 (JS, TS, CSS, JSON, Markdown).
- [ESLint](https://eslint.org/) — 플러그인 가능한 JavaScript 린터.
- [SonarQube](https://www.sonarsource.com/products/sonarqube/) — 지속적인 코드 품질 검사.
- [Hadolint](https://hadolint.github.io/hadolint/) — Dockerfile 린터.
- [EditorConfig](https://editorconfig.org/) — 편집기 간 일관된 코딩 스타일 유지.

## 테스트와 디버깅

- [Playwright](https://playwright.dev/) — 크로스 브라우저 종단간 테스트 프레임워크.
- [Vitest](https://vitest.dev/) — Vite 프로젝트를 위한 초고속 유닛 테스트 프레임워크.
- [Selenium](https://www.selenium.dev/) — 테스트용 브라우저 자동화.
- [ngrok](https://ngrok.com/) — localhost로의 안전한 검사 가능 터널.
- [React DevTools](https://react.dev/learn/react-developer-tools) — Chrome/Firefox용 React 컴포넌트 검사 도구.
- [Redux DevTools](https://github.com/reduxjs/redux-devtools) — Redux용 타임트래블 디버깅.

## DevOps와 클라우드

- [Docker](https://www.docker.com/) — 애플리케이션 컨테이너화 플랫폼.
- [Kubernetes](https://kubernetes.io/) — 프로덕션급 컨테이너 오케스트레이션.
- [Terraform](https://www.terraform.io/) — 클라우드 제공자 간 Infrastructure as Code.
- [Cloudflare Workers](https://workers.cloudflare.com/) — 엣지에서의 서버리스 컴퓨팅.
- [GitHub Actions](https://github.com/features/actions) — GitHub 내장 CI/CD.
- [Vercel](https://vercel.com/) — 프론트엔드 배포 및 서버리스 함수.
- [Netlify](https://www.netlify.com/) — 서버리스 백엔드가 포함된 웹 앱 배포.
- [WireGuard](https://www.wireguard.com/) — 현대적이고 안전한 VPN 터널.

## 데이터베이스 도구

- [DBeaver](https://dbeaver.io/) — 개발자용 범용 데이터베이스 도구.
- [Glim](https://github.com/NeoPanic/Glim) — SQLite 읽기 전용 탐색, JSON 트리, CSV 테이블을 지원하는 macOS 파일 뷰어.
- [TablePlus](https://tableplus.com/) — 모던 네이티브 데이터베이스 GUI.
- [RedisInsight](https://redis.com/redis-enterprise/redis-insight/) — Redis 시각화 및 관리 GUI.
- [pgAdmin](https://www.pgadmin.org/) — PostgreSQL 관리 및 개발 플랫폼.
- [MongoDB Compass](https://www.mongodb.com/products/compass) — MongoDB GUI.
- [SQLite Browser](https://sqlitebrowser.org/) — SQLite 데이터베이스용 시각적 도구.

## 프론트엔드 개발

- [Next.js](https://nextjs.org/) — 프로덕션급 앱을 위한 React 프레임워크.
- [Tailwind CSS](https://tailwindcss.com/) — 유틸리티 우선 CSS 프레임워크.
- [Vite](https://vitejs.dev/) — 차세대 프론트엔드 도구 체인.
- [shadcn/ui](https://ui.shadcn.com/) — 아름답게 디자인된 React 컴포넌트.
- [Framer Motion](https://www.framer.com/motion/) — React용 프로덕션 준비 애니메이션 라이브러리.
- [Radix UI](https://www.radix-ui.com/) — 스타일 없는 접근성 높은 React 컴포넌트.
- [Zustand](https://github.com/pmndrs/zustand) — 작고 빠른 React 상태 관리.
- [Recharts](https://recharts.org/) — 구성 가능한 React 차트 라이브러리.

## AI와 LLM 도구

- [Anthropic Claude](https://docs.anthropic.com/en/docs) — 안전한 AI 상호작용을 위한 Claude API.
- [LangChain](https://www.langchain.com/) — LLM 기반 애플리케이션 프레임워크.
- [Ollama](https://ollama.com/) — 로컬에서 LLM 실행.
- [Claude Code](https://docs.anthropic.com/en/docs/claude-code) — 터미널에서의 AI 코딩 어시스턴트.
- [Hermes Agent](https://hermes-agent.nousresearch.com/) — 오픈소스 AI 에이전트 프레임워크 (이 목록은 이것으로 구축되었습니다).
