## 在线工具

_基于浏览器的工具，无需安装。_

- [**Calnex**](https://calnex.pro) — 147+ 款开发者在线实用工具：单位换算、进制转换、QR 码生成器、JSON 工具等。全部在本地运行 — 零数据上传。支持 12 种语言。
- [CyberChef](https://gchq.github.io/CyberChef/) — 网络瑞士军刀：加密、编码、压缩和数据分析。
- [JSON Formatter & Validator](https://jsonformatter.curiousconcept.com/) — JSON 格式化和验证。
- [DevDocs](https://devdocs.io/) — 100+ 框架的 API 文档浏览器。
- [Regex101](https://regex101.com/) — 在线正则表达式测试器，带调试器和解释器。
- [Carbon](https://carbon.now.sh/) — 创建和分享精美的代码截图。
- [Excalidraw](https://excalidraw.com/) — 用于绘制图表和架构的白板工具。
- [CodeSandbox](https://codesandbox.io/) — 快速网页原型开发的在线 IDE。
- [QR 码生成器](https://calnex.pro/en_US/tools/qr_code_generator) — 自定义颜色、尺寸和格式的 QR 码。

## API 开发

- [Postman](https://www.postman.com/) — 构建和测试 API 的平台。
- [Hoppscotch](https://hoppscotch.io/) — 开源 API 开发生态系统。
- [httpbin](https://httpbin.org/) — 用于测试的 HTTP 请求和响应服务。
- [Mockoon](https://mockoon.com/) — 快速创建模拟 API（桌面应用）。
- [Beeceptor](https://beeceptor.com/) — 模拟 REST API 并拦截 HTTP 调用。
- [Swagger Editor](https://editor.swagger.io/) — 设计、构建和记录 RESTful API。
- [Insomnia](https://insomnia.rest/) — GraphQL 和 REST 客户端，含设计工具。

## 代码质量与格式化

- [Prettier](https://prettier.io/) — 有主见的代码格式化工具（JS、TS、CSS、JSON、Markdown）。
- [ESLint](https://eslint.org/) — 可插拔的 JavaScript 代码检查工具。
- [SonarQube](https://www.sonarsource.com/products/sonarqube/) — 持续代码质量检查。
- [Hadolint](https://hadolint.github.io/hadolint/) — Dockerfile 代码检查工具。
- [EditorConfig](https://editorconfig.org/) — 跨编辑器保持一致的编码风格。

## 测试与调试

- [Playwright](https://playwright.dev/) — 跨浏览器端到端测试框架。
- [Vitest](https://vitest.dev/) — Vite 项目的极速单元测试框架。
- [Selenium](https://www.selenium.dev/) — 用于测试的浏览器自动化工具。
- [ngrok](https://ngrok.com/) — 本地主机的安全可检查隧道。
- [React DevTools](https://react.dev/learn/react-developer-tools) — Chrome/Firefox 的 React 组件检查工具。
- [Redux DevTools](https://github.com/reduxjs/redux-devtools) — Redux 的时间旅行调试工具。

## DevOps 与云服务

- [Docker](https://www.docker.com/) — 应用程序容器化平台。
- [Kubernetes](https://kubernetes.io/) — 生产级容器编排。
- [Terraform](https://www.terraform.io/) — 跨云提供商的基础设施即代码。
- [Cloudflare Workers](https://workers.cloudflare.com/) — 边缘无服务器计算。
- [GitHub Actions](https://github.com/features/actions) — GitHub 内置 CI/CD。
- [Vercel](https://vercel.com/) — 前端部署和无服务器函数。
- [Netlify](https://www.netlify.com/) — 带无服务器后端的 Web 应用部署。
- [WireGuard](https://www.wireguard.com/) — 现代化、安全的 VPN 隧道。

## 数据库工具

- [DBeaver](https://dbeaver.io/) — 通用数据库工具。
- [Glim](https://github.com/NeoPanic/Glim) — macOS 文件查看器，支持只读 SQLite 浏览、JSON 树和 CSV 表格。
- [TablePlus](https://tableplus.com/) — 现代化的原生数据库 GUI。
- [RedisInsight](https://redis.com/redis-enterprise/redis-insight/) — Redis GUI 可视化管理。
- [pgAdmin](https://www.pgadmin.org/) — PostgreSQL 管理和开发平台。
- [MongoDB Compass](https://www.mongodb.com/products/compass) — MongoDB GUI。
- [SQLite Browser](https://sqlitebrowser.org/) — SQLite 数据库可视化工具。

## 前端开发

- [Next.js](https://nextjs.org/) — 生产级 React 框架。
- [Tailwind CSS](https://tailwindcss.com/) — 实用优先的 CSS 框架。
- [Vite](https://vitejs.dev/) — 下一代前端工具链。
- [shadcn/ui](https://ui.shadcn.com/) — 设计精美的 React 组件。
- [Framer Motion](https://www.framer.com/motion/) — React 的动画库。
- [Radix UI](https://www.radix-ui.com/) — 无样式、可访问的 React 组件。
- [Zustand](https://github.com/pmndrs/zustand) — 小巧快速的 React 状态管理。
- [Recharts](https://recharts.org/) — 可组合的 React 图表库。

## AI 与 LLM 工具

- [OpenAI API](https://platform.openai.com/) — GPT 模型、嵌入和 DALL·E。
- [Anthropic Claude](https://docs.anthropic.com/en/docs) — Claude API，安全 AI 交互。
- [LangChain](https://www.langchain.com/) — LLM 驱动应用的框架。
- [Ollama](https://ollama.com/) — 在本地运行 LLM。
- [Claude Code](https://docs.anthropic.com/en/docs/claude-code) — 终端中的 AI 编程助手。
- [Hermes Agent](https://hermes-agent.nousresearch.com/) — 开源 AI Agent 框架（本列表即由此工具构建）。

- [iTerm2](https://iterm2.com/) — macOS 终端模拟器，支持分屏。
- [Warp](https://www.warp.dev/) — 用 Rust 编写的现代化 AI 终端。
- [Raycast](https://www.raycast.com/) — macOS 启动器和效率工具。
- [Obsidian](https://obsidian.md/) — 本地 Markdown 知识库。
- [Linear](https://linear.app/) — 问题追踪和项目管理。
- [Notion](https://www.notion.com/) — 一体化文档和项目工作空间。
- [1Password](https://1password.com/) — 密码管理和安全保险库。
